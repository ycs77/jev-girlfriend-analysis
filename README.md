# 💔 Jev 求生慾即時警報器

當前任傳來訊息，你想知道她是不是在暗示什麼嗎？

當前任、正在曖昧的對象、或是恐怖情人傳訊息來時，人在緊張時常會讀不懂「字面下的微言大義」。Jev 專門用來拆解這些人類的「陰陽怪氣」。

## 常見女友訊息範例

可以使用以下範例訊息，來測試 Jev 的分析能力。

## 1. 興師問罪型 ── 表面風平浪靜，內心萬馬奔騰

這類訊息通常出現在你發了新動態、或交了新朋友之後，危險指數通常是 4~5 分。

* 「聽說你最近換新工作/搬新家了？看來沒有我之後，你過得越來越順遂了嘛～」
  * 潛台詞：憑什麼跟我分手後你過得更好？我現在很不爽。
* 「昨天在東區看到一個很像你的人，旁邊牽著一個女生，應該不是你吧？」
  * 潛台詞：那是誰？你竟然這麼快就交新女朋友了？給我解釋清楚。
* 「剛剛整理房間，看到你以前送我的項鍊。既然分手了，這垃圾我直接丟囉？」
  * 潛台詞：老娘在清空關於你的記憶，順便發個訊息刺探你會不會心痛、會不會挽留。
* 「你把 Netflix 密碼改掉了喔？我都不能看了」
  * 潛台詞：連這點便宜都不讓我佔，你真的很小氣、很絕情。
* 「按讚那個網美，是你的新菜喔？眼光變得很特別呢～」
  * 潛台詞：你竟然喜歡那種類型？看來你以前說只愛我是騙人的，順便踩一下你的審美。

## 2. 測試新對象與試探型 ── 假裝關心，實則刺探情報

看似無意的閒聊，其實每一步都是在試探你目前的感情狀態。

* 「最近有什麼好看的電影嗎？朋友叫我推薦，但我不知道現在流行什麼」
  * 潛台詞：你最近有沒有跟別人去約會看電影？
* 「今天經過我們以前常去的那家火鍋店，發現它倒閉了，突然有點感觸」
  * 潛台詞：我有懷舊光環，你看到這句話有沒有勾起回憶？心裡還有沒有我？
* 「下個月周杰倫演唱會，你應該買到票了吧？（以前說好要一起去的）」
  * 潛台詞：你買票是要帶誰去？如果是跟別的女生去我會崩潰。
* 「你最近是不是變瘦/變帥了？朋友在脆（Threads）上看到你發的照片，說你變很多」
  * 潛台詞：你是不是為了吸引新對象開始打扮了？
* 「希望你現在的另一半能比我更懂你的脾氣」
  * 潛台詞：我不信有誰能忍受你那種爛脾氣，你現在到底有沒有新對象？

## 3. 工具人招喚型 ── 沒事不聯絡，有事才想到你

利用你對她殘留的愧疚感或習慣，來幫她解決生活上的疑難雜症。

* 「我電腦突然開不起來，裡面有明天要交的報告，你可以幫我遠端看一下嗎？真的很急...」
  * 潛台詞：雖然分手了，但我知道你這個免費 IT 還是很好用。
* 「下週我要搬家，東西有點多，我找不到人幫忙開車，你可以借我一塊載嗎？」
  * 潛台詞：省下搬家公司的錢，反正你人好不會拒絕我。
* 「以前你幫我保的那張保單過期了，現在要怎麼續約啊？我看不懂業務傳的訊息」
  * 潛台詞：幫我處理一下，反正這是你的專業/你的責任。
* 「貓咪最近好像有點不舒服，都不太吃飯，牠是不是想你了？」
  * 潛台詞：用共同寵物當擋箭牌，叫你過來付醫藥費或幫忙帶去看醫生。
* 「這家餐廳你以前不是有熟識的店員可以訂位嗎？這禮拜六可以幫我訂四個人嗎？」
  * 潛台詞：我要跟我的新姊妹（或新對象）去吃，借你的面子用一下。

## 4. 深夜孤單寂寞型 ── 酒精作祟或一時脆弱

通常在週末深夜、情人節前夕或雨天傳來，情緒波動極大，隔天清醒可能會收回訊息。

* 「突然想到我們以前在海邊淋雨的那晚，那時候的我們真的好傻喔...」
  * 潛台詞：我現在很孤單，突然有點懷念有你陪伴的溫度。
* 「（傳來一張喝到一半的調酒照片）突然好想喝你調的酒」
  * 潛台詞：我喝醉了，心防降到最低，現在需要人陪（可能不只是你）。
* 「你睡了嗎？我剛剛做了一個很不好的夢，夢到你出事了，醒來覺得很不安」
  * 潛台詞：用夢境當藉口合法聯絡你，看你會不會溫柔地安慰我。
* 「對不起，我知道我不該傳訊息打擾你，但我真的找不到別人可以說話了...」
  * 潛台詞：以退為進，引發你的同情心，讓你主動留下來陪我聊天。
* 「如果那時候我們都沒有那麼脾氣硬，現在會不會不一樣？」
  * 潛台詞：我現在過得不順/很寂寞，開始後悔當時分手的決定了。
