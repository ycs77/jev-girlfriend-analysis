# 對話求生慾即時警報器

基於 [TypeSafe AI](https://typesafe.ai/) 的 **Jev System One 模型**建立的實驗專案。它根據你提供的訊息與脈絡，輸出對方**可能的心情狀態**與一項可直接採取的行動。

專案提供兩支腳本：一支處理目前交往中女友的訊息，另一支處理前女友的訊息。

## 安裝

需要 Node.js 20 或更新版本，以及 `TYPESAFE_API_KEY` 環境變數。

```sh
npm install
cp .env.example .env
```

在 `.env` 設定 `TYPESAFE_API_KEY`。

## 選擇對應腳本

### 女友：`girlfriend.ts`

用於仍在交往的關係。高心情指數時，建議會優先處理約定落空、衝突、想被傾聽或需要暫停互動的情境；文字與脈絡共同顯示可能有反話時，建議會改為先確認她真正比較在意的事；出現送命題式的測試問句時，建議會先辨識她在測什麼，不照字面回答。

```sh
npm run girlfriend -- "你不是說忙完會打給我嗎？" "原本約好晚上九點通話，但我延後了兩小時且沒有告知"
npm run girlfriend -- "沒事" "今天是她生日我忘記了，現在才想起來"
npm run girlfriend -- "隨便啊 你決定就好" "我問她晚餐想吃什麼"
npm run girlfriend -- "哦" "她問我週末要不要陪她 我說我跟朋友有約"
npm run girlfriend -- "那你先忙吧" "我跟她說我在打遊戲晚點回她"
npm run girlfriend -- "好喔！都可以啊！你開心就好我沒關係的" "她叫我跟前女友保持距離我覺得沒必要"
```

### 前女友：`ex-girlfriend.ts`

用於已結束交往關係。建議會優先限制回覆範圍：只處理交接與共同責任、尊重聯絡界線，不把回憶或近況直接視為復合邀請。

```sh
npm run ex-girlfriend -- "你的兩箱書我放管理室了，這週方便拿走嗎？" "已分手，物品待交接"
```

請依關係狀態選擇對應腳本。

## 輸出內容

兩支腳本都輸出心情指數、一項可直接採取的行動與該情境的地雷；女友腳本會另外輸出 Jev 對溝通訊號的有條件判讀。

| 欄位 | 意義 |
| --- | --- |
| 心情指數 | 0～100 的文字情緒張力估計，以及白話摘要。它表示訊息**可能**呈現的狀態，不是對方真實內心、人格或動機的事實判定。 |
| Jev 判讀 | 僅女友腳本輸出。說明訊息是否可能呈現表面放行、表面沒事、表面體貼、安全感試探或直接不滿等溝通訊號；證據不足時會明說無法判定。 |
| 建議行動事項 | 依關係狀態與訊息情境給出一項可直接採取的回覆方向，附可直接使用的回話句式。程式不會替你傳送訊息。 |
| 地雷 | 該情境下不能做的事、不能說的話；由 Jev 依訊息與脈絡判斷最易踩到的類型。 |

心情指數的白話區間：

| 分數 | 白話摘要 |
| --- | --- |
| 0～24 | 看起來平穩 |
| 25～49 | 可能有點在意或有感觸 |
| 50～74 | 可能不舒服、失望或關係緊繃 |
| 75～100 | 可能明顯生氣或高度不舒服 |

沒有足夠脈絡，且文字本身沒有明確情緒、請求或界線時，程式會顯示「無法可靠判讀」，不會硬塞一個心情分數。

## 女友的溝通訊號判讀

女友腳本會在同一個 Jev 請求中平行判斷訊息情境、情緒張力、溝通訊號和回覆重點。它會考慮下列可能的字面與在意事項落差：

- **表面放行**：看似同意去做某事，但脈絡顯示更在意陪伴、被商量或共同決定。
- **表面沒事**：看似說沒關係或算了，但脈絡顯示仍有未處理的事件、期待或受傷感。
- **表面體貼**：看似叫對方先忙、慢慢來或不打擾，但脈絡顯示可能在意被延後、忽略或沒有主動更新。
- **安全感試探**：用問句確認自己在你心中的位置或價值（如「你是不是沒有以前那麼愛我了」「我是不是變胖了」），脈絡顯示要的是保證與證據，不是字面答案。

驚嘆號、問號、訊息長度與簡短回覆也是 Jev 可參考的語氣線索，但不會以固定關鍵字或標點規則直接加分。短句、單一標點或沒有前後文的「沒事」、「隨便你」都不會直接被判定為生氣。

## 使用原則

- 只有對方直接寫出「我很生氣」、「我很難過」等情緒時，才可把它視為文字明示的情緒。
- 「好」、「沒事」、「隨便你」、單一標點或貼圖，沒有脈絡時不會直接判成生氣。
- 女友腳本的高分代表先放慢回應、處理具體事件與感受；不代表她一定生氣。
- 前女友腳本的高分代表先不要擴大互動；不代表她想復合、討厭你或一定不想回覆。
- 前女友出現明確拒絕聯絡、安全、騷擾、跟蹤或脅迫訊號時，建議行動會優先要求停止非必要接觸並遵守界線。
